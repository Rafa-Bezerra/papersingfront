1. Visão Geral do Sistema

O que é PaperSign?

PaperSign é um sistema de aprovação de documentos que automatiza o fluxo de aprovação de requisições, pedidos e documentos dentro de uma organização.

Objetivo Principal

Garantir que todos os documentos sejam aprovados pelos aprovadores corretos, de acordo com a hierarquia e faixa de valor definidas, de forma segura e auditada.

Componentes Principais

  • Alçadas: Níveis de aprovação por centro de custo
  • Aprovadores: Usuários com permissão para aprovar
  • Documentos: Requisições, pedidos ou outros documentos
  • Fluxo: Roteiro que o documento segue até aprovação final
  • Auditoria: Registro de todas as ações realizadas

Benefícios

  • Aprovação rápida e eficiente
  • Controle e auditoria completa
  • Redução de erros
  • Rastreabilidade total
  • Conformidade com políticas

2. Arquitetura e Componentes

Camadas do Sistema

Frontend (React/Next.js)

Interface do usuário responsiva. Componentes para visualizar documentos, aprovar, filtrar e pesquisar.

Backend (.NET 9)

APIs REST que processam requisições, gerenciam fluxos de aprovação e controlam acesso.

Banco de Dados (SQL Server)

Armazenamento persistente de alçadas, aprovadores, documentos e histórico de aprovações.

Autenticação

Sistema de login integrado com gestão de usuários e permissões por unidade.

Módulos Principais

  • Alçadas: Configuração de aprovadores por CC e faixa de valor
  • Documentos: Gerenciamento de documentos para aprovação
  • Requisições: Fluxo de requisições de compra e similares
  • Relatórios: Visualização de histórico de aprovações
  • Dashboard: Visão consolidada de pendências

4. Guia do Administrador

Configurar Alçadas

  1. Acesse "Alçadas" no menu
  2. Clique em "Nova Alçada"
  3. Selecione o centro de custo
  4. Defina o nível e faixa de valor
  5. Atribua o aprovador
  6. Salve a configuração

Incluir Aprovador em Vários CCs (T-ALC-LOTE)

  1. Clique em "Incluir aprovador em vários CCs"
  2. Selecione o usuário (buscar no GUSUARIO)
  3. Busque os CCs (por nome ou código, ex: "TI")
  4. Defina nível e faixa de valor
  5. Desmarque CCs que não pertencem ao grupo
  6. Clique "Incluir"
  7. Verifique o resumo (quantos incluídos vs já existiam)

Dica

Use essa funcionalidade para economizar tempo ao configurar aprovadores em vários centros de custo de uma mesma área (TI, RH, Financeiro, etc).

Gerenciar Usuários

  • Adicionar novos usuários ao sistema
  • Desativar usuários inativos
  • Atribuir unidades
  • Definir permissões

Monitorar Fluxo

  • Verificar documentos pendentes
  • Identificar gargalos no processo
  • Acompanhar SLA de aprovação

5. Documentação da API

Informação Restrita

Esta seção contém informações técnicas sensíveis. Compartilhe apenas com desenvolvedores autorizados.

Base URL

https://papersign.grupowaybrasil.com.br:5062/api

Autenticação

Todas as requisições devem incluir o Bearer token no header:

Authorization: Bearer {token}

Endpoints Principais

GET /api/Alcadas

Listar alçadas da unidade logada

GET /api/Alcadas Content-Type: application/json

POST /api/Alcadas

Criar nova alçada

POST /api/Alcadas { "centro_custo": "306.3.08.001", "nivel": 0, "valor_inicial": 0, "valor_final": 5000, "usuario": "USER123" }

POST /api/Alcadas/incluir-em-varios

Incluir aprovador em vários CCs (T-ALC-LOTE)

POST /api/Alcadas/incluir-em-varios { "usuario": "USER123", "centro_custos": ["306.3.08.001", "306.3.08.002"], "nivel": 0, "valor_inicial": 0, "valor_final": 5000 }

GET /api/Documentos

Listar documentos pendentes de aprovação

GET /api/Documentos?status=pendente&periodo=15

POST /api/Documentos/{id}/aprovar

Aprovar um documento

POST /api/Documentos/123/aprovar { "observacao": "Aprovado conforme políticas" }

Códigos de Erro

Código Significado
200 Sucesso
400 Requisição inválida
401 Não autenticado
403 Sem permissão
404 Não encontrado
500 Erro interno do servidor

Informação Restrita

Esta seção contém informações sobre a estrutura interna do banco de dados. Compartilhe apenas com DBAs e administradores de sistema.

Tabelas Principais

ALCADA

Coluna Tipo Descrição
ID INT PRIMARY KEY Identificador único
CENTRO_CUSTO VARCHAR(50) Código do CC
CENTRO_CUSTO_NOME VARCHAR(200) Nome do CC

ALCADAAPROVADORES

Coluna Tipo Descrição
ID_ALCADA INT FK Referência à alçada
USUARIO VARCHAR(50) Código do aprovador
NIVEL INT Nível de aprovação (0, 1, 2...)

VALOR_FINAL DECIMAL(12,2) Valor máximo

Relacionamentos

  • ALCADA (1) com multiplos (N) ALCADAAPROVADORES
  • ALCADAAPROVADORES (N) referencia GUSUARIO
  • Documentos (N) para ALCADAAPROVADORES

7. Fluxos de Aprovação

Fluxo Padrão de Aprovação

Documento - Nível 0 - Nível 1 - Aprovado

Cenários de Reprovação

Atenção

Se reprovado em qualquer nível, o documento volta para o início da fila. O solicitante deve revisar e reenviar.

Escalação

Se um aprovador não responder em X dias, o documento é escalado para o próximo nível.

Documentos com Certificado A1

Documentos que requerem assinatura digital seguem um fluxo especial:

  • Aprovação padrão
  • Solicitação de certificado A1 (opcional)
  • Assinatura digital
  • Finalização

8. Troubleshooting

Problema: Documento não aparece na lista

  • Verifique filtros aplicados (status, período, solicitante)
  • Confirme que é aprovador daquele CC
  • Limpe os filtros e tente novamente

Problema: Erro ao aprovar documento

  • Erro 500: Contate suporte técnico
  • Erro "PDF header not found": Documento pode estar corrompido, reenvie
  • Erro "Certificado inválido": Verifique certificado A1

Problema: Usuário não consegue fazer login

  • Verifique credenciais
  • Confirme que usuário está ativo em GUSUARIO
  • Limpe cache do navegador
  • Tente outro navegador

Problema: Aprovador não aparece na lista

  • Confirme que usuário existe em GUSUARIO
  • Verifique que usuário está ativo
  • Confirme unidade está correta
  • Atualize a página (F5)

9. Perguntas Frequentes

P: Como incluir um aprovador em vários CCs de uma vez?

R: Use a funcionalidade "Incluir aprovador em vários CCs" na aba Alçadas. Selecione o usuário, busque os CCs desejados, desmarque os que não pertencem e clique Incluir.

P: Posso editar uma alçada já existente?

R: Sim. Clique na alçada e edite os campos necessários. Não é possível alterar o CC (crie uma nova alçada).

P: O que acontece se o mesmo usuário está em dois níveis diferentes?

R: O sistema roteia para o menor nível em que o usuário está. Se estiver em 0 e 1, vai direto para 0.

P: Como remover um aprovador?

R: Edite a alçada e clique no botão "Remover" próximo ao aprovador.

P: O certificado A1 é obrigatório?

R: Não. Certificado A1 é opcional tanto em documentos internos quanto externos.

P: Como rastrear a aprovação de um documento?

R: Clique em "Detalhes" ou "Histórico" para ver todos os passos da aprovação.

P: Qual é o SLA de aprovação?

R: Depende da política da sua unidade. Consulte o administrador do sistema.
