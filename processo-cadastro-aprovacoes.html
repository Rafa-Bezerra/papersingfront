1. Visão Geral do Processo

O PaperSign é um sistema de aprovação de documentos que integra cadastro de alçadas, centros de custo, usuários aprovadores e fluxos de aprovação com diferentes níveis e faixas de valor.

2. Módulos Principais

2.1 Cadastro de Alçadas

Objetivo

Definir os níveis de aprovação por centro de custo e faixa de valor.

Dados

  • Centro de Custo (CC)
  • Nível de aprovação (0, 1, 2, 3...)
  • Faixa de valor (inicial - final)
  • Usuário aprovador

Funcionalidades

  • Criar nova alçada
  • Editar alçada existente
  • Incluir aprovador em vários CCs de uma vez (T-ALC-LOTE)
  • Remover aprovador

2.2 Cadastro de Usuários

Objetivo

Gerenciar usuários do sistema e suas permissões.

Dados

  • Código de usuário
  • Nome
  • E-mail
  • Unidade
  • Cargo/Função
  • Ativo/Inativo

2.3 Fluxo de Aprovação

Objetivo

Rotear documentos para aprovação conforme alçadas configuradas.

Passos

  • Documento entra no sistema
  • Sistema identifica CC e valor
  • Sistema identifica aprovadores (alçada + nível)
  • Documento é roteado para aprovadores
  • Aprovadores aprovam/reprovam
  • Documento segue para próximo nível ou conclui

5. Faixas de Valor

Cada alçada define uma faixa de valor inicial até final para a qual o aprovador tem competência.

Exemplo

  • Alçada 1: R$ 0 até R$ 5.000 (Gestor)
  • Alçada 2: R$ 5.001 até R$ 50.000 (Gerente)
  • Alçada 3: R$ 50.001 até R$ 999.999 (Diretor)

6. Funcionalidades Novas (T-ALC-LOTE)

Incluir Aprovador em Vários CCs

Permite adicionar um mesmo aprovador em múltiplos centros de custo de uma vez.

Fluxo

  1. Selecionar usuário (busca)
  2. Buscar CCs (por nome ou código)
  3. Selecionar nível e faixa de valor
  4. Sistema lista CCs encontrados (checkbox)
  5. Desmarcar CCs que não pertencem ao grupo
  6. Clicar "Incluir"
  7. Sistema grava e exibe resumo (quantos incluídos/já existiam)

7. Regras Importantes

  • Unidade: Aprovadores só podem ser incluídos na unidade logada
  • Usuário ativo: Apenas usuários ativos no GUSUARIO aparecem para seleção
  • Não duplica: Se aprovador já existe naquele nível, não duplica
  • Transação: Tudo é gravado em uma única transação (tudo ou nada)
  • Auditoria: Registra quem fez e quando cada operação
  • Sem exclusão: A funcionalidade só inclui, nunca remove aprovadores

9. Perguntas Frequentes

P: Posso adicionar o mesmo aprovador em todos os CCs?

R: Sim, deixe a busca em branco (ou use "*") para listar todos os CCs da unidade.

P: O que acontece se o usuário já é aprovador naquele nível?

R: O sistema não duplica. Apenas mostra no resumo "já existia".

P: Preciso remover um aprovador?

R: Use a tela de Alçadas normal (editar alçada e remover).

P: Quem pode usar essa funcionalidade?

R: Apenas usuários com permissão para editar alçadas.
